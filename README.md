# Grammy Awards Website Engagement Analysis

## Overview

This project analyzes website engagement data taken from Grammy.com and RecordingAcademy.com to evaluate the impact of separating the websites to better target different audiences. The project explores serveral key engagement metrics, including:

 - website traffic
 - pages per session
 - bounce rate
 - average session duration
 - user age demographics
 - desktop and mobile device traffic
 - competitve benchmarking against the American Music Awards website   

## Tools Used
- Python
- Pandas
- Plotly
- Jupyter Notebook

## Running the Project
1. Clone this repository
2. Install required Python packages
3. Open notebooks/grammy_web_analytics.ipynb
4. Run all notebook cells to repoduce the analysis
